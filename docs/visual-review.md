# 参考图还原与视觉检查

本轮以用户提供的五组照片为版式参考，实际代码位置：

- 首页世界/中国：`pages/index/index.wxml` 的 atlas 区块，`utils/atlas.js` 绘制整幅区域地图。照片贴片、航迹、光点、分区深浅均由数据生成；不是贴一张不可操作的设计图。
- 地图进入城市：日落照片封面 → Overview / Photos / Itinerary / Notes → 动态胶卷 → 深色胶片查看器 → 无边框大图。
- Trips：英文衬线标题、年份筛选、左图右文列表；进入独立的 Day 01 时间线，含时间、地点、说明、照片。
- Moments：深色世界地图、追光航线、照片条、月份滑块；切换米白 GOLDEN HOUR 相册，支持日出、日落和城市筛选。
- Souvenirs：软木板、绳索、夹子、照片、独立瓷器挂件与纸吊牌；全屏添加及详情页。

`runtime-review/` 中的 12 张图片由真实 WXML/WXSS、页面状态及相同 Canvas 绘制代码在浏览器等效渲染后截取，用于发现样式与资源问题。不是微信开发者工具截图，不能代替微信官方编译和真机验证，也不表示和用户拍摄的参考图达到了逐像素一致。

本轮图片为生成式摄影风格演示素材，只有用户自己的上传才是真实旅行记录。英文手写字体 Allura 采用 SIL Open Font License，见 `Allura-OFL.txt`。地图数据出处和正式发布前的授权/审图核验说明见 `map-sources.md`。


本轮追加保持页面结构和主配色，加入 DM Serif Display 标题字体（SIL OFL，见 DMSerifDisplay-OFL.txt）、地图缩放/平移、逐场日出日落连线和 10 国 15 城示例。鼠标滚轮通过 scroll-view 的滚动事件驱动缩放；纯悬停事件取决于运行端提供的事件，拖动/触控始终保留。缩放数学、坐标保存和示例幂等迁移由自动测试覆盖，微信工具实际事件分发仍需复检。
