ROAM · 新版复古旅行手账

1. 从 GitHub main 下载最新 ZIP，解压到新文件夹。
2. 微信开发者工具 → 导入项目。
3. 选择直接含 app.json、project.config.json、pages、assets 的目录。
4. 普通编译。无需 npm 安装、网页服务器或云开发。
5. 首页应该是 ROAM 大字、完整复古地图、蓝色区域、照片贴片、金色光点。
6. 底部 Trips 是旅行列表，Moments 是日出日落，Profile → 我的收藏柜是纪念品。

地图城市 → 日落封面 → 点击胶卷 → 深色照片页 → 再点主图放大。
下载新版后必须打开新版目录；只点编译不会从 GitHub 自动更新。
原 AppID 已保留，需要有相应开发权限的微信账号。
现有记录仅存在旧工具项目的本地缓存中，不要随意清理数据缓存。
云端无法代替微信官方编译；遇到编译错误请发具体错误截图。
