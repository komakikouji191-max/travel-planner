# 旅迹 · ROAM

原生微信旅行回忆小程序。所有代码、图片、示例数据及设计参考均在本项目内，无需下载外部图片或运行网页服务器。

## 在微信开发者工具打开

1. 导入**本文件所在的整个目录**，选择目录后应能看到 `project.config.json`、`app.json`、`pages/`、`assets/`。
2. 配置已保留你上传项目中的 AppID。请使用有该小程序开发权限的微信账号登录；没有权限时需在开发者工具中改用可用的测试号或自己的 AppID。
3. 点击「普通编译」，入口为 `pages/index/index`。无需 npm 安装、构建 npm 或配置云开发。
4. 首次打开会展示本地示例旅行、照片插画、日出日落和纪念品。底部可切换足迹、旅行、追光、我的；「我的 → 我的收藏柜」可查看纪念品。
5. 顶部「页面设计参考已内置」可打开四张设计参考大图。这些是效果图；返回后可使用实际功能。

如果是在旧目录上覆盖，请先备份自己的资料，再移除旧程序文件，复制本项目的全部内容。确保 `project.config.json` 和 `app.json` 位于同一层，`miniprogramRoot` 为 `./`，不要保留旧的 `miniprogram/` 入口。开发者工具若仍加载旧界面，可清除编译缓存后重新编译；清除数据缓存会删除你已有的本地旅行记录。

## 项目结构

```
travel-planner/
  project.config.json          开发者工具项目配置（保留原 AppID）
  project.private.config.json  本地工具设置（纠正旧项目名称）
  app.js / app.json / app.wxss  小程序入口与全局样式
  sitemap.json
  pages/index/                 可操作的手账页面
  pages/preview/               内置设计参考查看器
  assets/                      所有运行图片，全部本地打包
  docs/page-design.png          完整设计参考原图
  scripts/check-project.cjs     项目完整性检查
  tests/miniprogram.test.cjs    功能逻辑测试
```

旧版网页 `index.html`、`server.js`、`style.css` 已从新版移除，根目录 `app.js` 已替换为微信入口；旧网页启动命令也已移除。本项目使用标准 WebView 渲染，不沿用上传的 Skyline 空白模板。

## 实际功能

- 足迹地图：微信原生底图、城市标记与深浅光圈；同城多次旅行可选择具体旅行。
- 旅行胶卷：横向滚动、随手指倾斜、松手复位，点击进入微信原生大图预览。
- 每日足迹：按日期和时间记录地点、照片、感想；可新增、编辑、删除旅行和地点。
- 追光：地点标记为日出或日落后自动收录，按场次统计，同场多张照片只计算一次。
- 纪念品：相册或拍照上传，关联城市和旅行，填写类别、日期、故事，预览大图及删除。
- 本地持久保存：记录用微信本地存储，照片用持久文件。保存失败保留表单并回滚数据；删除后清理不再引用的照片。
- 导出记录 JSON（不包含照片文件，尚无导入恢复）。

示例图片为插画，不是用户真实旅行照片。顶部移除示例功能仅删除内置示例及其关联纪念品，保留自己新增的旅行。

## 尚未完成的效果与平台条件

照片与记录仅保存在当前设备，尚无账号、云备份、换机同步。清理数据或卸载会丢失记录，请保留相册原照片。

地图目前使用城市标记/区域光圈，未完成整幅复古世界地图、国家/省份行政边界染色及呼吸光效。世界按钮改变地图浏览中心，不能保证整幅世界地图同屏显示。追光尚无独立全球路线时间轴；胶卷尚无柔性弯曲或共享元素放大动画；纪念品尚无自动抠图和分类筛选。

微信底图需要联网，位置选点和真机分享等能力受 AppID、平台权限与隐私设置约束。项目声明了主动选点使用的 `chooseLocation`；正式发布前应在微信后台配置实际使用的隐私保护指引和接口权限。拒绝位置授权仍可手动填城市和坐标。

## 检查

不安装依赖即可在 Node.js 18+ 运行：

```sh
npm run check
npm test
```

检查路由、入口、图片引用、JS/JSON 和本地数据操作。云端不能运行微信开发者工具，官方 WXML/WXSS 编译、底图、相册与位置授权、照片持久化及真机手感仍需在开发者工具和手机验证。设计参考图不是运行截图。
