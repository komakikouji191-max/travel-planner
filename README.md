# 旅迹 · Travel Planner

主要开发目标已改为原生微信小程序。小程序代码位于 `miniprogram/`；此前的网页版本暂时保留在根目录。

## 微信小程序（Windows）

1. 安装官方微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开开发者工具，用微信扫码登录，选择“小程序” → “导入项目”。
3. 选择整个 `travel-planner` 文件夹（包含 `project.config.json` 的目录）。
4. 本地演示配置使用 `touristappid`。可选择工具提供的测试号模式；正式开发和真机预览请使用自己的小程序 AppID，在开发者工具项目设置中填写。
5. 选择不使用云服务并编译，在模拟器中创建旅行、添加地点、查看预算。

小程序不需要 Node.js、npm、后端或 API 密钥。行程通过微信本地存储保存；复制地址后可在地图应用搜索，完整行程可复制到聊天或笔记。目前没有内嵌地图、自动路线计算、云同步或多人协作。测试号能力以微信开发者工具当前规则为准，正式发布需要自己的 AppID、相应资质和微信审核。

当前云环境已检查小程序 JavaScript 语法、JSON 配置，并用模拟微信 API 验证增删改、存储恢复、预算计算、输入校验和复制内容。云环境不能运行 Windows 微信开发者工具，WXML/WXSS 编译及真机体验仍需在工具中验证。

## 此前网页版本的启动

需要 Node.js 18 或更新版本，无需安装第三方运行依赖。

```sh
cd /workspace/travel-planner
npm run dev
```

默认端口为 3000，可通过 `PORT` 覆盖。`npm run check` 检查 JavaScript 语法。

## 功能

- 创建和切换旅行，设置日期、人数、天数与预算
- 按天添加、编辑、删除地点，填写时间、分类、地址与预估费用
- 按时间查看地点顺序，通过高德地图链接搜索位置
- 查看分类预算统计，导出文本行程

首次打开提供杭州示例行程。数据仅存在当前浏览器；清除浏览器数据会丢失行程，建议导出备份。导出文件供阅读，暂不支持导入。尚未提供云同步、多人协作、地图路线计算或真实票价查询。
