# ROAM · 旅迹

复古旅行手账原生微信小程序。米白纸张、英文衬线字、手写字体、深蓝地图、暖金光点、胶卷与纪念品收藏板。

## 在微信开发者工具查看最新版

1. 从 GitHub `main` 分支下载 ZIP，解压到**新的目录**。
2. 微信开发者工具 → 导入项目，目录选择**直接包含 `app.json`、`project.config.json`、`pages/`、`assets/` 的那一层**。不要选只有一个同名子文件夹的外层目录。
3. 配置已保留原项目 AppID，使用有开发权限的账号；如无权限，请在工具中配置可用的测试号或自己的 AppID。
4. 选择「普通编译」。无需安装依赖、构建 npm、启动服务器或配置云开发。
5. 仅点击编译不会从 GitHub 自动更新文件；下载新版本后要导入新目录。若仍显示旧样式，先确认目录，再清除**编译缓存**。不要随意清除数据缓存，那会删除本地旅行记录。

首页为 `ROAM` 大标题与整幅世界地图，可切换 `China`。底部是 Map / Trips / + / Moments / Profile。

## 页面与交互

- **Map**：离线 Canvas 区域地图、真实几何轮廓、按不同城市数量加深的国家/省区色块、呼吸光点、照片贴片与虚线飞机航迹。点击城市进入回忆，点击中国省区查看照片摘要。支持 Cities / Provinces / My Route。
- **City**：全幅日落封面、英文城市名、日期及寄语；下方纸张面板含 Overview / Photos / Itinerary / Notes。回忆胶卷随手势倾斜、松手复位。
- **Photo**：深色胶片浏览器、照片序号、底部缩略图、拍摄信息、收藏与分享菜单；点击主图切换沉浸大图，长按进入微信原生图片预览，可缩放或保存。
- **Trips**：年份筛选、英文城市列表与照片统计；点击进入按天排列的独立足迹时间线，点击地点名可编辑。
- **Moments**：THE LIGHT I'VE CHASED 深色地图、航迹、照片条、月份滑块及统计；右上角切换 GOLDEN HOUR 米白相册，可按日出/日落与城市筛选。
- **Souvenirs**：Profile → 我的收藏柜，软木板展示挂件、照片和吊牌。相机按钮添加，上传相册照片、选择旅行、类别和日期、写故事；点物品打开详情。示例瓷器使用透明素材，普通上传保留照片原背景。

「＋」统一创建旅行、地点/追光或纪念品。记录与照片仅保存在当前设备；照片使用持久文件路径。存储失败保留表单并回滚；移除示例保留自己的旅行。JSON 导出不包含照片二进制，目前尚无导入恢复或云同步。请保留手机相册原片。

首次打开提供标注为示例的演示足迹。已有真实记录不会被替换。地图配色、数量和图片由自己的记录决定，不会伪造参考图中的 42 个国家、207 个城市等统计。

## 检查和实际边界

```sh
npm run check
npm test
```

Node.js 18+，无第三方运行依赖。自动检查入口、图片路径、JS/JSON；12 项测试覆盖增删改、永久照片路径、失败回滚、地图省区命中、国家色阶统计、城市到胶卷/时间线的导航、筛选和大图状态。

`docs/runtime-review/` 是用真实模板/样式/页面状态和相同地图绘制代码生成的**浏览器等效渲染截图**，不是微信运行截图。参考图还原说明见 `docs/visual-review.md`。

云端无法运行官方微信开发者工具，WXML/WXSS 官方编译、Canvas/字体兼容性、系统安全区、相册和位置授权、真机手感仍须在微信工具中验证。参考图中的字体和系统图标会随设备变化，尚未验证逐像素一致。地图数据授权和正式发布前审图要求见 `docs/map-sources.md`，当前用于开发预览。

无账号、云备份、跨设备同步、自动轨迹采集或运行时自动抠图。正式发布前需配置微信隐私保护指引与实际使用的位置接口权限；拒绝位置权限可手动记录城市坐标。此前普通底图和独立设计参考展示页已移除，首页展示实际交互代码。
